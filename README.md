# Battery Charge Limit

Cinnamon panel applet to set the battery charge limit through TLP.

Pick **Save battery** (75-80% by default), **Full charge** or **Custom**.
Changes last until reboot unless you click **Keep after reboot**.

## Requirements

- Cinnamon
- TLP 1.4 or newer
- `pkexec` (on Debian/Ubuntu: `sudo apt install pkexec`)
- A laptop whose battery supports charge thresholds. Check with:
  `ls /sys/class/power_supply/BAT*/charge_control_end_threshold`

## Install

```bash
sudo ./install-system.sh install
./install-applet.sh install
```

Then right-click the panel → Applets → add **Battery Charge Limit**.

`install-system.sh` installs a small root helper and a polkit policy, comments
out the threshold lines in `/etc/tlp.conf` (backup kept as
`/etc/tlp.conf.pre-charge-thresholds`) and saves your settings in
`/etc/tlp.d/90-charge-thresholds.conf`.

## Uninstall

```bash
./install-applet.sh uninstall
sudo ./install-system.sh uninstall
```

This restores `/etc/tlp.conf` from the backup.

## Notes

- Changes ask for your password (remembered for a few minutes).
- Stop limit can't go below 50%. Some vendors only accept certain values;
  TLP's error is shown as a notification if so.
- Only the main battery is handled.
- Log of changes: `journalctl -t charge-thresholds`
- Icons are generated by `tools/make-icons.py`.
